Privacy Policy

Application: BM3 Racing Automation
Last updated: May 13, 2026

1. Overview

BM3 Racing Automation is a personal automation tool that publishes YouTube Shorts content to TikTok on behalf of the sole operator (BM3 Racing). This application is not available to third-party users.

2. Data We Access

This application accesses the following TikTok data exclusively for the account owner:

  • video.publish – to directly publish video content to the operator's TikTok account.
  • video.upload – to upload video files to TikTok for publishing.
  • user.info.basic – to verify the authenticated user's identity.

3. How We Use Data

All data accessed via the TikTok API is used solely to automate the posting of original video content created by the account owner. No data is shared with third parties, stored beyond the duration of an active session, or used for advertising or analytics purposes.

4. Data Retention

We do not store TikTok user data beyond what is temporarily held in memory during the execution of the automation script. OAuth tokens are stored locally on the operator's own device and are never transmitted to external servers.

5. Third-Party Sharing

We do not sell, trade, or otherwise transfer any information to third parties.

6. Security

Access tokens are stored in a local .env file on the operator's private machine and are never exposed publicly.
